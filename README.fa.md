# سرور MCP گپیفای (gapify-mcp-server)

## این سرور چه کاری انجام می‌دهد؟

این یک **سرور MCP** است که سامانه‌ی پشتیبانی مشتریان [گپیفای](https://app.gapify.ai) را به دستیارهای هوش مصنوعی مثل **Claude** وصل می‌کند.

MCP (پروتکل زمینه‌ی مدل) استانداردی است که به دستیار هوش مصنوعی اجازه می‌دهد با سرویس‌های بیرونی کار کند. با نصب این سرور، می‌توانید به زبان ساده (فارسی یا انگلیسی) از Claude بخواهید کارهای گپیفای را برایتان انجام دهد، بدون اینکه وارد پنل گپیفای شوید.

برای مثال:

- «گفتگوهای باز امروز را نشان بده»
- «به گفتگوی ۴۲ جواب بده: سفارش شما ارسال شد»
- «مخاطب با شماره‌ی ۰۹۱۲۱۲۳۴۵۶۷ را پیدا کن»
- «گفتگوی ۴۲ را به تیم پشتیبانی ارجاع بده و برچسب vip بزن»
- «هفته‌ی گذشته چند گفتگو بسته شد؟»

## چه امکاناتی دارد؟

این سرور ۱۱۸ ابزار دارد که تقریباً همه‌ی API گپیفای را پوشش می‌دهد:

| بخش | کارهایی که می‌شود انجام داد |
| --- | --- |
| گفتگوها | فهرست، جستجو، فیلتر، ساخت، تغییر وضعیت (باز، بسته، در انتظار)، اولویت‌بندی، ارجاع به کارشناس یا تیم |
| پیام‌ها | خواندن پیام‌های یک گفتگو، ارسال پیام یا یادداشت داخلی، حذف پیام |
| مخاطبان | فهرست، جستجو با نام، ایمیل یا شماره تلفن، ساخت، ویرایش، حذف |
| برچسب‌ها | دیدن و تنظیم برچسب‌های گفتگو و مخاطب |
| کارشناسان و تیم‌ها | افزودن، ویرایش و حذف کارشناس، مدیریت تیم‌ها و اعضای آن‌ها |
| صندوق‌های ورودی | فهرست، ساخت، ویرایش، تعیین کارشناسان و ربات هر صندوق |
| گزارش‌ها | آمار گفتگوها، زمان اولین پاسخ، زمان حل مسئله، آمار هر کارشناس |
| سایر | پاسخ‌های آماده، ویژگی‌های سفارشی، فیلترهای ذخیره‌شده، اتوماسیون‌ها، وب‌هوک‌ها، ربات‌ها، مرکز راهنما |

اگر کاری در ابزارها نبود، ابزار `gapify_raw_request` می‌تواند هر درخواستی را مستقیم به API گپیفای بفرستد.

## پشتیبانی از زبان فارسی

- متن‌های فارسی (نام مخاطب، متن پیام، یادداشت، عبارت جستجو) **بدون تغییر و بدون ترجمه** به گپیفای فرستاده می‌شوند.
- شناسه‌ها، شماره‌ها و شماره تلفن‌ها را می‌توانید با **ارقام فارسی** بنویسید. سرور خودش آن‌ها را به ارقام انگلیسی تبدیل می‌کند. مثلاً `۰۹۱۲ ۳۴۵ ۶۷۸۹` به `09123456789` تبدیل می‌شود.
- برای گزینه‌های بله/خیر می‌توانید «بله» یا «خیر» بنویسید.

## پیش‌نیازها

۱. **Node.js نسخه‌ی ۱۸ یا بالاتر**. از [nodejs.org](https://nodejs.org) نصب کنید. برای بررسی، در ترمینال بنویسید `node --version`.

۲. **توکن دسترسی گپیفای (Access Token)**:
   وارد گپیفای شوید ← روی پروفایل خود کلیک کنید ← **Profile Settings** ← بخش **Access Token** را کپی کنید.

۳. **شناسه‌ی حساب (Account ID)**:
   عددی است که در آدرس پنل گپیفای می‌بینید. مثلاً در آدرس `app.gapify.ai/app/accounts/12/dashboard` شناسه‌ی حساب `12` است.

> ⚠️ توکن دسترسی مثل رمز عبور است. آن را با کسی به اشتراک نگذارید و در جایی عمومی (مثل گیت‌هاب) قرار ندهید.

## نصب و اتصال

### روی Claude Code

در ترمینال این دستور را اجرا کنید. به جای `your-token` توکن خود و به جای `12` شناسه‌ی حساب خود را بگذارید:

```bash
claude mcp add --scope user gapify -e GAPIFY_API_ACCESS_TOKEN=your-token -e GAPIFY_ACCOUNT_ID=12 -- npx -y gapify-mcp-server
```

بعد Claude Code را باز کنید و دستور `/mcp` را بزنید تا مطمئن شوید سرور gapify وصل شده است.

### روی Claude Desktop

۱. فایل تنظیمات را باز کنید:
   - ویندوز: `%APPDATA%\Claude\claude_desktop_config.json`
   - مک: `~/Library/Application Support/Claude/claude_desktop_config.json`

   (در Claude Desktop از منوی **Settings ← Developer ← Edit Config** هم می‌توانید آن را باز کنید.)

۲. این بخش را به فایل اضافه کنید:

```json
{
  "mcpServers": {
    "gapify": {
      "command": "npx",
      "args": ["-y", "gapify-mcp-server"],
      "env": {
        "GAPIFY_API_ACCESS_TOKEN": "your-token",
        "GAPIFY_ACCOUNT_ID": "12"
      }
    }
  }
}
```

۳. Claude Desktop را کامل ببندید و دوباره باز کنید.

### تنظیمات

| متغیر | ضروری؟ | توضیح |
| --- | --- | --- |
| `GAPIFY_API_ACCESS_TOKEN` | بله | توکن دسترسی از Profile Settings |
| `GAPIFY_ACCOUNT_ID` | پیشنهادی | شناسه‌ی حساب؛ اگر تنظیم شود لازم نیست هر بار آن را بگویید |
| `GAPIFY_BASE_URL` | خیر | آدرس سرور گپیفای؛ پیش‌فرض `https://app.gapify.ai` |
| `GAPIFY_PLATFORM_APP_API_KEY` | فقط برای مدیر کل | برای ابزارهای مدیریت پلتفرم (ساخت حساب و کاربر) |
| `GAPIFY_AGENT_BOT_API_KEY` | خیر | توکن ربات، به عنوان جایگزین برای ارسال پیام |

## نحوه‌ی استفاده

بعد از اتصال، کافی است خواسته‌ی خود را به زبان ساده بنویسید. Claude خودش ابزار مناسب را انتخاب و اجرا می‌کند. چند نمونه:

**پیگیری گفتگوها**
- «گفتگوهای بازی که به هیچ‌کس ارجاع نشده را نشان بده»
- «آخرین پیام‌های گفتگوی ۱۵۰ را بخوان و خلاصه کن»

**پاسخ به مشتری**
- «به گفتگوی ۱۵۰ بنویس: سلام، درخواست شما ثبت شد و تا فردا پیگیری می‌شود»
- «یک یادداشت داخلی روی گفتگوی ۱۵۰ بگذار: مشتری ویژه است»

**مدیریت مخاطبان**
- «مخاطبی به نام مریم احمدی با شماره‌ی ۰۹۱۲۱۲۳۴۵۶۷ بساز»
- «گفتگوهای قبلی مخاطب علی رضایی را پیدا کن»

**گزارش‌گیری**
- «میانگین زمان اولین پاسخ در ماه گذشته چقدر بوده؟»
- «کدام کارشناس این هفته بیشترین گفتگو را بسته است؟»

## نکته‌های ایمنی

- Claude قبل از اجرای کارهایی که چیزی را **تغییر یا حذف** می‌کنند (ارسال پیام، حذف مخاطب و…) معمولاً از شما تأیید می‌گیرد. قبل از تأیید، درخواست را با دقت بخوانید.
- ابزارهای حذف برگشت‌پذیر نیستند.
- این سرور فقط کارهایی را می‌تواند انجام دهد که صاحب توکن در گپیفای اجازه‌اش را دارد.

## رفع مشکلات رایج

| پیام خطا | علت احتمالی | راه حل |
| --- | --- | --- |
| `HTTP 401` | توکن تنظیم نشده یا اشتباه است | توکن را دوباره از Profile Settings کپی کنید |
| `HTTP 403` | کاربر شما اجازه‌ی این کار را ندارد | با مدیر حساب گپیفای هماهنگ کنید |
| `HTTP 404` | شناسه‌ی گفتگو، مخاطب یا حساب اشتباه است | شناسه‌ها و `GAPIFY_ACCOUNT_ID` را بررسی کنید |
| `HTTP 422` | اطلاعات ارسالی ناقص یا نادرست است | فیلدهای لازم را کامل کنید |
| سرور در `/mcp` وصل نمی‌شود | Node.js نصب نیست یا نسخه‌اش قدیمی است | `node --version` را بررسی کنید (باید ۱۸ یا بالاتر باشد) |
